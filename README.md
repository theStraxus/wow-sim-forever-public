# WoW: Forever simulator (unofficial site)

This repository holds only the **built static website** for a community simulator of
World of Warcraft: Forever beta data. It has no build system. Open the site, not these files.

- Site: https://thestraxus.github.io/wow-sim-forever-public/
- Based on [WoWSims Classic](https://github.com/wowsims/classic) and its Forever conversions.
  MIT licensed; the license text is in `LICENSE`.
- Unofficial. Not affiliated with or endorsed by Blizzard Entertainment. Game names, icons
  and data belong to their owners.
- Results are simulations built on beta client data and community assumptions. The benchmark
  pages list their caveats; treat the numbers as estimates, not measurements.
